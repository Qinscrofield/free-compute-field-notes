# Telnyx 试用金买美国号码：号能白拿，功能要升级（实测记录）

核实日期：2026-11-14
账户级别：Pretrial，试用 AI credits $25（30 天）

## 实测结论

- Pretrial 账户可用试用金买 **1 个美国本地号码**：页面标价开通费 $0.00 / 月费 $0.00 的号码真实存在（纽约 718 仅剩 2 个、929 有 50+ 个；212、646、332、347、917 当时无真实库存）。
- 实际成交：订单总额 $0.00（未付真钱），但试用金被扣 $2.00（$25 → $23），应为激活类费用；试用等级下门户不提供订单号与费用明细。
- 号码本身带 SMS/MMS 能力（美国境内收发），状态 Active。

## 免费的天花板（重点）

1. **Pretrial 级别禁止把号码分配给 Messaging Profile**（页面报错 “This feature is not permitted at this account level”），所以短信实际上收发不了；通话同理需要先配 Connection。
2. 升级到 Trial 的第一步是身份评估（GitHub / LinkedIn 连接，或 Onfido 证件验证）。实测 GitHub 验证被 Telnyx 评估拒绝，未给原因。
3. 即便升到 Trial：短信只能与已验证号码互通（出站仅限已验证目的地、每天上限 100 条），且升级会把剩余试用金重置为 $5。
4. 通用短信能力要到 Paid 级：需本人手机号验证、服务地址、开启 2FA，并用信用卡/PayPal 真实付款。
5. 官方试用条款提示：试用期所购号码若账户一直不升级，购买后 30 天内可能被回收。

Telnyx 试用 = 「号码免费拿、功能付费墙」。想要一个能真正收短信的美国号码，免费路线在 Telnyx 走不通。
